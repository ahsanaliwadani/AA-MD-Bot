⚡ Theme Command

.theme
→ Shows all available themes.

.theme list
→ List themes with preview.

.theme set <theme>

Example:
.theme set cyberpunk

.theme current
→ Shows current theme.

.theme random
→ Select random theme.

.theme reset
→ Restore default theme.

━━━━━━━━━━━━━━━━━━━━━━

👤 User Theme

Each user can have their own menu theme.

Store in database:

{
  jid: "...",
  menuTheme: "cyberpunk"
}

Changing one user's theme must NOT affect others.
